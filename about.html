QUANTUM LOTTO Lab은 로또 6/45와 연금복권 720+의 공개 당첨 데이터를 정리하고, 번호 조합의 구조를 직접 살펴볼 수 있게 만든 무료 개인 프로젝트입니다.

01 · Purpose

‘예측’보다 ‘이해’에 초점을 맞춥니다

복권 관련 화면에는 근거를 확인하기 어려운 예측 문구와 과도한 확신이 쉽게 섞입니다. 이 서비스는 공개 데이터를 사용하고, 실제 코드가 계산하는 기준만 화면에 표시하며, 결과의 한계를 함께 설명하는 것을 목표로 합니다.

서비스의 역할
번호를 대신 결정하거나 당첨을 약속하는 것이 아니라, 사용자가 고른 조건과 조합의 모양을 일관된 방식으로 정리해 주는 참고 도구입니다.

02 · Features

현재 제공하는 기능

두 복권 모드

로또 6/45와 연금복권 720+ 데이터를 한 화면에서 전환합니다.

조건형 조합 생성

고정수·제외수와 일부 구조 조건을 반영해 참고 조합을 만듭니다.

통계 대시보드

최근 범위별 빈도, 미출현 간격과 분포 지표를 시각적으로 정리합니다.

당첨 결과 대조

저장한 목표 회차와 공개 당첨 결과를 비교해 일치 상태를 표시합니다.

공개 타임라인

공개 데이터 소스의 조합 기록을 회차 기준으로 확인합니다.

내 저장소·이미지

조합을 현재 브라우저에 보관하고 복권 슬립 형식 이미지로 저장합니다.

닉네임별 로컬 공간

선택한 닉네임마다 같은 브라우저 안에서 저장 조합을 분리해 다시 확인합니다.

03 · Process

데이터에서 화면까지

01

불러오기

게시된 Google Sheets CSV와 공개 Apps Script 응답에서 데이터를 가져옵니다.

02

계산하기

브라우저에서 빈도·간격·홀짝·저고·합계·AC 등 구조 지표를 계산합니다.

03

보여주기

선택 조건과 함께 결과 카드, 통계표, 저장 목록으로 정리합니다.

계정 서버나 유료 결제 시스템은 없습니다. 닉네임, 설정과 보관 조합은 원칙적으로 현재 브라우저의 localStorage에 저장되며 다른 기기와 동기화되지 않습니다.

04 · Principles

네 가지 운영 원칙

01계산 기준과 데이터 출처를 가능한 범위에서 공개합니다.
02당첨·수익을 보장하거나 구매를 재촉하지 않습니다.
03로그인 없이 핵심 기능을 무료로 제공합니다.

후원은 선택 사항이며 후원 여부가 기능, 등급, 생성 결과에 영향을 주지 않습니다.

05 · Limits

서비스가 하지 않는 것

  • 동행복권의 공식 서비스가 아니며 복권을 판매하거나 구매를 대행하지 않습니다.
  • 인공지능, 신경망 또는 검증되지 않은 모델이 미래 당첨 번호를 예측한다고 주장하지 않습니다.
  • 통계 등급이나 점수가 실제 당첨 확률을 높인다고 설명하지 않습니다.
  • 외부 데이터의 지연·누락·오류가 없다고 보장하지 않습니다.
  • 브라우저 저장 데이터를 서버 백업하거나 다른 기기와 동기화하지 않습니다.
복권은 독립 확률 추첨입니다. 실제 구매와 당첨 확인은 동행복권 공식 안내를 기준으로 하고, 만 19세 이상이 정한 여가 예산 안에서 이용해 주세요.
