02 · Data processing

서비스가 직접 수집하는 정보

MIX645는 개인정보 입력란을 두지 않습니다. 사용자가 조합 만들기를 실행하면 대상 회차, 로또 모드, 생성 번호 6개, 전략 번호·전략명과 묶음 내 순번을 처리합니다. 서비스 기록에는 저장 시각, 대상 회차, 생성 번호와 전략명이 남으며 최근 기록은 사이트에서 공개됩니다.

이 기록에는 이름, 닉네임, 전화번호, 이메일 주소 또는 회원 식별자가 포함되지 않습니다. 자체 방문 통계 스크립트, 광고 쿠키, 소셜 로그인과 웹 결제 모듈도 사용하지 않습니다.

다만 사이트 접속 과정에서 호스팅 및 데이터 제공자의 서버에는 일반적인 네트워크 요청 정보가 전달될 수 있습니다. 이에 대한 자세한 내용은 아래 ‘운영 환경’ 항목을 확인해 주세요.

현재 서비스 코드는 쿠키, localStorage 또는 sessionStorage에 이용자 정보와 생성 결과를 저장하지 않습니다. 현재 화면 결과와 직접 입력한 QR 번호는 새로고침하면 사라지지만, 조합 만들기로 자동 저장된 공개 기록은 저장·당첨 기록 영역에서 다시 표시될 수 있습니다.

공개 조합 기록은 당첨 대조와 서비스 기록 제공 목적이 유지되는 동안 보관되며, 운영자가 오류·중복·운영상 필요를 확인해 삭제할 수 있습니다. 특정 기록 삭제가 필요하면 대상 회차, 전략명과 6개 번호를 이메일로 알려 주세요.

브라우저는 성능을 위해 HTML, CSS, JavaScript 파일을 일반 캐시에 임시 보관할 수 있습니다. 이 동작은 브라우저 설정에서 관리할 수 있으며 서비스의 회원 식별이나 추적에 사용되지 않습니다.
