01 · Summary

운영자가 직접 수집하는 가입 정보는 없습니다

서비스에는 회원가입, 로그인, 댓글, 문의 폼 또는 자체 결제 기능이 없습니다. 선택 입력인 닉네임은 로컬 저장소를 구분하는 용도로만 현재 브라우저에 남으며, 생성 조합·설정과 함께 운영자 서버로 전송해 계정에 보관하지 않습니다.

0회원가입 필수 항목
Local설정·조합은 현재 브라우저 저장
External데이터·호스팅 요청은 외부 제공자 경유
이 방침은 현재 배포된 정적 사이트 구조를 기준으로 합니다. 향후 로그인, 자체 서버, 광고 분석 또는 입력 폼을 추가한다면 실제 적용 전에 방침과 동의 절차를 갱신해야 합니다.

02 · Browser storage

브라우저 localStorage에 남는 정보

화면 설정과 사용자가 저장한 조합을 유지하기 위해 현재 기기의 브라우저 저장 공간을 사용합니다.

저장 항목내용목적
로컬 닉네임이용자가 선택 입력한 1~12자 닉네임같은 브라우저 안에서 닉네임별 저장소 구분
화면 테마밝기 테마 선택값다음 방문 때 화면 설정 유지
생성 설정이월수·인접수 범위, 중복 방지, 정렬 선택사용자 환경 유지
로또 저장소선택 번호, 목표 회차, 계산 지표조합 보관과 결과 대조
연금복권 저장소조 번호, 여섯 자리, 목표 회차, 계산 지표조합 보관과 결과 대조

이 정보는 같은 브라우저 프로필 안에만 남으며 운영자가 자체 서버로 수집하지 않습니다. 닉네임은 비밀번호나 본인 확인 수단이 아니며, 같은 브라우저를 사용하는 사람은 닉네임을 다시 입력해 해당 로컬 저장소를 볼 수 있습니다. 닉네임을 적용한 상태에서 카드나 슬립 이미지를 저장하면 이미지에 닉네임이 표시될 수 있으므로 공유 전에 확인해 주세요. 브라우저의 사이트 데이터 삭제 기능이나 서비스의 저장소 비우기 기능을 이용하면 삭제할 수 있습니다.

03 · External requests

데이터와 파일을 불러올 때 외부 통신이 발생합니다

서비스 작동 과정에서 아래 제3자에게 네트워크 요청이 전송됩니다. 외부 제공자는 요청 처리 과정에서 IP 주소, 요청 시각, 브라우저·기기 정보, 접속 로그 등을 자동으로 처리할 수 있으며 각 제공자의 개인정보 처리 기준이 적용됩니다.

제공자·서비스이용 목적전송되는 일반 정보
GitHub Pages웹사이트 파일 호스팅과 전송IP, 요청 URL, 접속 시각, 브라우저 정보 등 서버 로그
Google Sheets 공개 CSV로또·연금복권 공개 데이터 불러오기일반적인 웹 요청 정보
Google Apps Script공개 타임라인 및 관련 데이터 요청일반적인 웹 요청 정보
html2canvas CDN조합 이미지를 브라우저에서 생성할 라이브러리 다운로드라이브러리 파일 요청에 필요한 접속 정보
공식·상담 외부 링크동행복권 결과 또는 1336 안내 확인링크를 선택한 경우 해당 사이트 접속 정보

조합 이미지의 화면 캡처 처리는 브라우저 안에서 수행됩니다. 서비스는 방문자 수 집계를 위한 자체 분석 도구나 광고 추적 스크립트를 현재 사용하지 않습니다.

04 · Support & contact

자율 후원과 이메일 문의

카카오페이 QR 후원

QR 코드를 스캔해 카카오페이 앱에서 후원을 선택하면 해당 거래는 이용자와 카카오페이 및 수취인 사이에서 처리됩니다. 이 웹사이트 자체는 카카오 계정, 결제수단 또는 결제 인증 정보를 수집하지 않습니다. 다만 수취인은 카카오페이가 제공하는 범위에서 거래 정보나 송금자 표시 정보를 확인할 수 있습니다.

이메일 문의

이메일 링크를 선택하면 이용자의 메일 앱이 열립니다. 이용자가 보내는 이메일 주소와 본문은 문의 답변을 위해 처리되며, 메일 제공자의 정책도 적용됩니다. 주민등록번호, 금융정보, 복권 원본 사진 등 불필요한 민감 정보는 보내지 마세요.

05 · Retention

보유 기간과 삭제 방법

  • 브라우저 저장 정보: 이용자가 삭제하거나 브라우저 저장소가 초기화될 때까지 현재 기기에 남습니다.
  • 운영자 보유 사본: 생성 설정과 저장 조합은 운영자 서버에 별도 사본을 만들지 않습니다.
  • 이메일 문의: 답변과 분쟁 대응에 필요한 기간 동안 보관한 뒤 목적이 끝나면 삭제합니다. 법령상 보관 의무가 있는 경우는 해당 기간을 따릅니다.
  • 후원 거래: 카카오페이와 수취인의 거래 기록은 결제·세무 관련 기준 및 각 제공자의 정책에 따라 처리될 수 있습니다.
  • 외부 접속 로그: GitHub·Google·CDN 등 외부 제공자의 보유 기간과 삭제 기준을 따릅니다.
직접 삭제
브라우저 설정에서 azit4376-blip.github.io의 사이트 데이터 또는 localStorage를 삭제하면 이 기기에 저장된 설정과 조합을 지울 수 있습니다. 삭제한 로컬 데이터는 사이트에서 복구할 수 없습니다.

06 · Your choices

이용자가 선택할 수 있는 것

  • 브라우저 저장을 원하지 않으면 저장 기능을 사용하지 않거나 사이트 데이터를 삭제할 수 있습니다.
  • 외부 데이터 요청을 차단할 수 있으나 당첨 데이터·타임라인·이미지 기능이 동작하지 않을 수 있습니다.
  • 운영자에게 직접 제공한 이메일 문의 정보의 열람, 정정 또는 삭제를 요청할 수 있습니다.
  • 외부 제공자가 처리한 정보에 관한 요청은 해당 제공자의 절차를 이용해야 할 수 있습니다.

07 · Age restriction

만 19세 미만 이용 제한

서비스는 복권 관련 통계 정보이므로 만 19세 이상 이용자를 대상으로 합니다. 운영자는 미성년자의 가입 정보를 수집하지 않지만, 보호자는 브라우저와 기기의 접근을 적절히 관리해 주세요.
