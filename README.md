# QUANTUM LOTTO Lab

로또 6/45와 연금복권 720+ 공개 데이터를 브라우저에서 분석하는 정적 웹사이트입니다. 회원가입과 자체 서버 저장 없이 동작하며, 생성 조합은 통계적 참고 정보입니다.

## 배포 파일

GitHub Pages 저장소의 `lotto` 사이트 루트에 이 폴더의 파일과 하위 폴더를 그대로 올립니다. 특히 아래 신규 파일이 빠지면 하단 문서 프레임이 정상 표시되지 않습니다.

- `about.html`, `terms.html`
- `guide1.html`, `guide2.html`, `privacy.html`
- `documents.css`, `documents.js`
- `qrcode.png`

문서 링크는 메인 화면의 `<dialog>` 안에서 열리며, JavaScript나 `<dialog>`를 지원하지 않는 환경에서는 각 HTML 문서로 이동하는 링크가 대체 동작을 합니다.

## 닉네임 저장 방식

닉네임은 회원 계정이 아니라 현재 브라우저의 로컬 프로필 키입니다. 같은 브라우저에서 같은 닉네임을 적용하면 해당 닉네임의 로또·연금복권 저장소를 다시 불러옵니다. GitHub Pages는 정적 호스팅이라 이용자 데이터를 서버에 쓸 수 없으므로 다른 기기와는 동기화되지 않습니다.

향후 기기 간 동기화나 공개 조회가 필요하면 별도 데이터베이스와 인증·접근제어·입력 검증·삭제 기능을 갖춘 백엔드를 추가하고, 그 전에 개인정보처리방침을 갱신해야 합니다. GitHub 토큰을 프런트엔드 코드에 넣어 저장소에 직접 기록하는 방식은 토큰이 노출되므로 사용하면 안 됩니다.

## 로컬 확인

사이트 폴더에서 다음 중 하나로 정적 서버를 실행합니다.

```text
python -m http.server 4180
```

그다음 `http://127.0.0.1:4180/`에 접속합니다. `file://`로 직접 열면 외부 데이터 요청이 브라우저 정책 때문에 실패할 수 있습니다.

## 배포 전 검사

Node.js가 설치된 환경에서 다음 명령을 실행합니다.

```text
node tools/site-check.mjs
```

필수 파일, 내부 링크, 문서 프레임 연결, 중복 ID, JavaScript 문법과 개인정보처리방침 핵심 항목을 한 번에 확인합니다.

## 외부 연결

- Google Sheets 공개 CSV: 당첨 데이터
- Google Apps Script: 공개 타임라인 데이터
- html2canvas CDN: 조합 이미지 생성 라이브러리
- GitHub Pages: 정적 호스팅

외부 제공자의 장애나 정책 변경 시 일부 기능이 지연될 수 있습니다. 당첨 여부와 공식 규칙은 항상 동행복권을 최종 기준으로 확인합니다.
